# 2026-10-26

- 修复「时长未解析完时选集快速全部播完」bug：
  - 根因：扫描先列出文件、后台补齐时长，期间章节 `duration = 0`，`Chapter.parseMarkData()` 会把 marks 塌缩为 [0..1]；`MediaItemProvider` 用该 mark 构建 `ClippingConfiguration(endPositionMs=1)`，ExoPlayer 把每个条目裁剪成 ~1ms，逐条瞬时结束导致整本"秒播完"。
  - 修复：`core/playback/.../session/MediaItemProvider.kt` — 当 `chapter.duration <= 0` 时不再裁剪结尾（`endPositionMs = C.TIME_END_OF_SOURCE`），metadata `durationMs` 也置 null，整文件正常播放，等后台补齐时长后自动恢复精确选段。
  - 新增测试：`core/playback/src/test/kotlin/.../session/MediaItemProviderTest.kt`（duration=0 不裁剪 + duration 已知正常裁剪两例，需 `@RunWith(AndroidJUnit4)`）。
  - 环境备忘：本机无 `local.properties`，已创建指向 `/home/v/Android/Sdk`（已被 gitignore）；测试命令 `./gradlew :core:playback:testDebugUnitTest`。
