## HiFi 模式设置开关（float output）

用户需求「支持一下hifi」→ 确认为在设置页加「HiFi 模式」开关，开启时走高精度直出链路。

实现（media3 1.10.1，核心 API：`DefaultRenderersFactory.setEnableAudioFloatOutput(true)`）：

- `core/data/api` StoreQualifiers.kt：新增 `HiFiModeStore` qualifier
- `core/data/impl` StoreModule.kt：新增 `DataStore<Boolean>` provider（fileName "hiFiMode"，默认 false）
- `core/playback` OnlyAudioRenderersFactory.kt：构造时 `runBlocking` 读开关并 `setEnableAudioFloatOutput(...)`
- `features/settings`：SettingsViewState/SettingsListener/SettingsViewModel/Settings.kt 加开关行（AudioFile 图标 + Switch）
- 字符串：`settings.playback.hifi_mode.title/summary`，values + values-zh-rCN
- SettingsViewModelTest：补 hiFiModeStore 参数和 toggle 测试（未运行，按用户规则）

关键事实（已通过反编译 media3 1.10.1 AAR + 官方 javadoc 验证）：
- float 输出仅对高解析 PCM（int24/int32）源生效（`shouldUseFloatOutput` = enableFloatOutput && isEncodingHighResolutionPcm），16bit 音源行为不变
- float 模式下 DefaultAudioProcessorChain 被替换为 ToFloatPcmAudioProcessor：跳过静音（SilenceSkipping）失效；变速自动改走 AudioTrack.setPlaybackParams（无需额外开关，`shouldApplyAudioProcessorPlaybackParameters` 逻辑保证）
- 开关在播放器创建时读取（PlaybackService.onCreate → PlaybackGraph），运行中切换需重启应用生效，摘要文案已如实说明
- 与既有的 media3_audio_offload feature flag 相互独立，未做耦合
