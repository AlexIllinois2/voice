## 自动衔接播放的转码改为非打扰通知

用户需求：非手动触发的自动加载（自动衔接播放下一章时的预转码）不要独占式弹窗 loading，改成非打扰、完成自动消失的通知。

- `TranscodeState.Running` 加 `auto: Boolean` 字段，区分手动转码与自动预转码
- `TranscodeManager.ensureConverted(uri, auto)`：自动路径传 `auto=true`
- 新增 `core/playback/.../CurrentMediaUriHolder.kt`：记录当前播放的媒体 uri，供 `PlaybackModule` 判定"非当前书/当前章"的转码是否属于自动衔接
- `TranscodingDataSource` 接线：ensureConverted 透传 auto
- `BookPlayController`：auto 转码不再走独占 overlay，改发非打扰 snackbar（完成自动消失）；手动触发仍走原来的 loading
- `TranscodeOverlay`：标题右侧小 loading（大 loading 移到标题后是上一轮改动）
- `BookPlayViewModelTest` 补 `transcodeManager` mock 参数（本改动遗留的测试编译错误，本次顺带修复）

## 首页添加书籍：移除设置-有声书文件夹 + 添加入口 + 结果以书架为准

用户需求（原话要点）：移除设置-有声书文件夹；首页搜索框设置图标左边加添加图标，点击添加书籍；首页书籍列表是唯一权威数据源，添加成功（书出现在首页）才算成功，没成功弹窗显示详细错误，可直接保存错误信息到本地。

### 设置页移除（features/settings）
- 删 `Settings.kt`「有声书文件夹」ListItem；`SettingsListener/SettingsViewModel` 删 `openFolderPicker()`；`SettingsViewModelTest` 删对应测试

### 首页添加图标（features/bookOverview）
- `TopBarTrailingIcon`：设置图标左侧常驻 Add 图标（`VoiceIcons.Add`，空库沿用 AddBookHint），新增 `AddBookIcon.kt`
- `onAddBookClick` → `navigator.goTo(Destination.AddContent(Origin.Default))`
- **删除整条迁移死代码链**：`BookFolderIcon.kt`、"FolderPickerMovedToSettings" 对话框、`showFolderPickerIcon`、`FolderPickerMovedDialogShownStore`（StoreQualifiers + StoreModule）、`FolderPickerInSettingsFeatureFlag`（FeatureFlagBindingContainer）、`FolderPickerMigrationInstallTimeCutoff`、`AppInfoProvider` 注入
- 注意：`library.folders.title` 字符串保留（FolderPickerView 顶栏仍在用），只删了 `settings.library.folders.summary` / `library.folders.moved.*`（39 个 locale）

### 添加结果校验（features/folderPicker/addcontent）
- `AddContentViewModel` 注入 `BookRepository`/`LogStore`/`ErrorReportSaver`（build.gradle 加 `projects.core.logging.inapp`）
- 新增 `AddState`（Idle/Adding/Failed），compose mutableStateOf 暴露给 UI
- **成功判定 = `BookRepository.flow()` 出现 `BookId(添加的uri)` 的书**（首页列表即唯一权威数据源）；失败判定先到先得：① 扫描 job 结束（含 enrich）仍无书 ② 5 分钟超时兜底
- `MediaScanTrigger` 新增 `currentScanJob()`：`scan()` 保持返回 Unit（返回 Job 会在 attach/deleteBook 等调用点触发 `-Werror` 的 "Unused return value"），`currentScanJob()` 取最近一次扫描 job 用于 await；**比等 `scannerActive` true→false 可靠**——restart 扫描会先发旧 job 的 false 再起新扫描，存在误判竞态
- 失败 detail 组装：时间/uri/类型/失败原因/堆栈 + `LogStore` 中 add 起点之后新增的日志条目
- 成功后把 addState 重置 Idle 再导航（否则测试断言 Idle 失败）
- `dismissError()`：Default → setRoot(BookOverview)，Onboarding → goBack

### UI 与保存错误（SelectFolder）
- Adding：两个按钮禁用 + LinearProgressIndicator + `add_book.adding` 文案

- `SelectFolderButton` 加 `enabled` 参数；关闭按钮复用 `common.action.close`、图标描述复用 `common.action.add`
